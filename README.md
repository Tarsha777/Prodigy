# Sentiment Analysis of Product Ratings (Prodigy Internship)

This project was developed as part of my internship at **Prodigy**, focused on building a machine learning model to analyze product reviews and predict sentiment (Positive, Negative, Neutral).

## 🚀 Project Overview
- **Goal**: Predict sentiment of product ratings to help businesses gain insights from customer feedback.
- **Dataset**: Product reviews with associated star ratings (details anonymized as per confidentiality).
- **Tech Stack**: Python, Jupyter, scikit-learn, pandas, matplotlib, nltk

## 💡 Key Highlights
- Preprocessing of text data (cleaning, tokenization, stopword removal)
- Sentiment classification using machine learning
- Model evaluation with accuracy, F1-score, confusion matrix
